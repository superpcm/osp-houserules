DM's Toolkit

  • Rest Restore all spell slots for player characters.
  • Export Characters Download all player characters as a JSON file.
  • Give XP Award XP to selected player characters.
  • Set XP Set a character's XP to a specific value.
  • Edit Ability Score Set a character's ability score to a specific value.
  • Edit Skill Value Set a character's skill target to a specific value.
  • Import Monsters Paste a JSON array of monster stat blocks to create Actor documents.
  • Update Monster Attacks Patch attacks-per-round on existing monsters from the original import JSON.
  • Player Lock {{#if playerLockActive}}LOCKED — players cannot roll dice or move tokens.{{else}}Players can roll dice and move tokens freely.{{/if}}
  • Lock the Store {{#if storeLockActive}}LOCKED — players cannot drag items to their inventory.{{else}}Players can drag items from item lists freely.{{/if}}
