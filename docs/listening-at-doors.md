# Listening at Doors Chance by Race (OSE)

| Race      | Listening at Doors Chance | Notes                                      |
|-----------|--------------------------|---------------------------------------------|
| Human     | 1-in-6                   |                                             |
| Dwarf     | 2-in-6                   |                                             |
| Elf       | 2-in-6                   |                                             |
| Halfling  | 2-in-6                   |                                             |
| Gnome     | 2-in-6                   | (if allowed as PC)                          |
| Half-Elf  | 1-in-6                   | (if allowed as PC)                          |
| Half-Orc  | 1-in-6                   | (if allowed as PC)                          |

- Thieves and similar classes may improve this chance, usually to 2-in-6 at 1st level, increasing with advancement.
- Roll a d6; a result equal to or less than the chance indicates success.
